# Fastab

一键呼出的markdown记事本（Windows x64系统）。

当前版本：**1.5.6**

## 核心能力与操作说明

* 开机自启，后台运行，一键呼出（默认Alt + Z），随时写入，markdown渲染，一键收回（默认Alt + Z）。
* 创建：点击顶栏「新建」按钮创建空白笔记。
* 排序：笔记卡片可「置顶 / 前移 / 后移/ 置底」。
* 三种界面：**工作台**界面、**查看**界面（渲染markdown）、**编辑**界面。
    **工作台**单击笔记卡片进入**查看**，工作台双击笔记卡片进入**编辑**。
    **查看**时双击或按 Enter 进入**编辑**，按 Esc 返回**工作台**。
    **编辑**时按“保存”按钮或 Ctrl + Enter回到**查看**；按“关闭”按钮实际是“保存并关闭”，回到**工作台**。
* 查看界面下，顶栏显示笔记小块，可直接点击小块或 Ctrl + PageUp / PageDown 左右切换。**编辑界面下小块置灰不可切换。**
* 显示：可设置大字体，对近视用户友好。
* 数据在「文档\\Fastab\\data」，每次保存自动备份到「文档\\Fastab\\FastabBackup」（最多 20 份）；设置页可查看备份目录与立即备份。
* 设置页支持「导出笔记及配置 / 导入笔记及配置」（**导入直接重置所有数据**，导入时选择文件夹内部需包含notes.json与preferences.json两个文件）。

## 快捷键

|快捷键|功能|可否修改|
|:-:|:-:|:-:|
|`Alt + Z`|呼出/收起面板（默认值）|可改（设置页）|
|`Enter`|笔记打开时进入编辑；卡片聚焦时进入编辑|固定|
|`Esc`|查看笔记时返回工作台（编辑模式下不响应）|固定|
|`Ctrl + PageUp/PageDown`|查看时切换到上一条 / 下一条笔记（编辑模式下不响应）|固定|
|`Ctrl + Enter`|编辑时保存|固定|
|`Ctrl + Z`|撤销|固定|
|`Ctrl + Shift + Z`|重做|固定|
|`Tab` / `Shift + Tab`|编辑时缩进 / 反缩进选中行|固定|
|`Ctrl + D`|编辑时删除光标所在行 / 选区覆盖的行|固定|
|`Ctrl + F`|编辑时打开查找面板|固定|
|`Ctrl + H`|编辑时打开查找替换面板|固定|

### 1.5.5 更新内容

#### 查找面板：「替换」也会把焦点交给正文

* 点「**替换**」按钮时焦点移到正文，命中的文字被原生蓝底选中：

  * 第一次点「替换」：还没有选中任何命中时，**先跳到第一个命中并选中**（不替换）；
  * 再次点「替换」：**替换当前选中项，并选中下一个命中**，焦点仍留在正文；
  * 之后每点一次都是“替换 + 选中下一个”。
* 找不到命中时焦点留在查找框，方便继续改关键词。
* 「**全部替换**」保持不变：一次性替换全部命中，**无法**在正文里同时选中多个不连续命中（`textarea` 只有一个选区），焦点仍留在查找框。

#### 设置面板

* 快捷键说明里的 `Ctrl/Cmd` 统一改为 **`Ctrl`**（`Ctrl + Enter` / `Ctrl + Z` / `Ctrl + Shift + Z` / `Ctrl + D` / `Ctrl + F` / `Ctrl + H`）。
* 设置弹窗改为**不透明背景**（新增 `--ws-dialog-bg`，日间 `#ffffff`、夜间 `#101724`），不再透出后面的工作台；弹窗外的遮罩层保持半透明。
* 开机自启本就有「首次启动自动开启、之后尊重用户开关」的逻辑，本次未改动。

### 1.5.4 更新内容

#### 查找：点 ↑/↓ 时把焦点交给正文

* 点击查找面板的 **↑ / ↓** 按钮后，**焦点移到正文**，命中的文字用系统蓝色的原生选区选中：

  * 可以直接对命中内容做选择、复制、修改；
  * 跳转仍会把该行滚到视口内（走滚动看守器的 `scrollApi.set()`，不会被弹回）。
* **Enter 不再作为“查找下一个”**：在查找框里按回车不会跳转、不会提交，焦点仍留在查找框，避免误触。
* 输入关键词时焦点仍在查找框（此时不跳转、也不需要选中），要定位命中请点 ↑/↓。
* 关闭面板（× 或 Esc）后焦点回到正文。

#### 移除 1.5.3 的镜像高亮层

* 删除 1.5.3 里那层“文字透明、只画色块”的镜像高亮层及其全部 CSS/状态代码。
* 现在的高亮完全来自原生选区：**点 ↑/↓ 让正文获得焦点后**，选中即蓝底可见。

#### 版本与产物

* 版本号升至 **1.5.4**（`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、设置页版本号同步）。

### 1.5.3 更新内容

#### 修复：查找时看不到“当前匹配项”

* 问题：编辑模式下打开查找面板后，输入关键词、按 ↑/↓ 都看不到命中的字段被选中，只有关掉面板才看到。
* 根因：**Chromium 不绘制失焦控件的选区**。查找时焦点在查找框里，正文 `<textarea>` 处于失焦状态，所以 `setSelectionRange()` 虽然执行了、选区也在，但屏幕上看不见（改 `::selection` 颜色也没用，1.5.2 就是这么试的）。
* 修复：在编辑器中新增一层**命中高亮层**（与 textarea 同尺寸、同字体、同内边距、同滚动的镜像层，文字透明只画色块，`pointer-events: none`）：

  * 所有命中都显示浅色高亮；
  * **当前匹配**用更深的色块标出，按 ↑/↓ 会跟着切换；
  * 高亮层与正文滚动同步，换行、缩放、字号档位都保持一致；
  * 原生选区仍然保留（复制/粘贴行为不变），只是不再依赖它来“看得见”。
* 该高亮层只在查找面板打开时存在，关闭后完全移除，不影响正常编辑。

#### 版本与产物

* 版本号升至 **1.5.3**（`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、设置页版本号同步）。
* 安装包改名 **`Fastab\\\_1.5.3\\\_x64-setup.exe`**。

### 1.5.2 更新内容

#### 查找命中：黄色高亮改为普通蓝色选区

* 去掉 1.5.1 引入的黄色高亮（`::selection` 黄色底），命中词仍会被**选中**，↑/↓ 按钮可切换选中的命中项，`n/N` 计数不变。
* 选区颜色改为显式的“蓝底白字”（跟随主题强调色 `--ws-accent`）：

  * 之所以显式指定颜色，是因为查找时焦点在查找框、正文处于**失焦**状态，Chromium 对失焦控件的选区默认可能不绘制或变浅，显式配色能保证任何情况下都稳定可见。
  * 夜间主题的强调色偏浅，此时用浅蓝底 + 深色字以保证对比度。

#### 编辑模式下的顶栏笔记小块

* 编辑模式整排置灰不变，**当前小块额外做“灰度版颜色反转”**：灰底（`#9ca3af`）+ 近白文字 + 加粗，用来和查看模式的黑/白反转呼应。
* 该小块仍然是 `disabled`，点击无效、鼠标指针为普通箭头。

#### 版本与产物

* 版本号升至 **1.5.2**（`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、设置页版本号同步）。

### 1.5.1 更新内容

#### 搜索：去掉拼音，只按字符匹配

* 搜索框占位符改为「**搜索**」（英文 `Search`），不再提示支持拼音。
* 匹配规则简化为**大小写不敏感的子串匹配**，匹配源仍为「标题 + 正文」；`zhongwen` 这类拼音输入不再命中「中文」。
* 保留 1.5.0 的全角/半角、重音归一化与"空查询不匹配一切"的保护，英文/全角输入仍然正常。
* 删除 `pinyin-pro` 依赖，前端包体随之变小。

#### 顶栏笔记小块：当前项改为「颜色反转」

* 当前笔记小块不再用透明边框，而是**和其它小块一样的外框**，通过**填充色与文字色互换**来突出：

  * 日间主题：近黑填充（`--ws-text-strong`）+ 近白文字（`--ws-card-bg`）；
  * 夜间主题：浅色填充 + 深色文字（同样跟随主题变量，不写死黑白）。
* 鼠标悬停在当前小块上时保持强调配色，不会被普通小块的 hover 背景覆盖。
* 编辑模式下仍是整排置灰、不可点击（灰度规则的优先级高于选中态）。

##### 查找替换面板

* 宽度加宽到原来的 **2 倍**（`min(960px, 100% - 24px)`），并在编辑器底部**水平居中**（用 margin 居中，不引入额外 transform）。
* 面板字体、字号、控件高度统一为与详情页「关闭」按钮一致（12px / `--ws-font-ui`，输入框与按钮高 30px）。
* 去掉面板的 `backdrop-filter: blur()` 与半透明背景，改为不透明卡片底色——这层背景模糊会把面板提升为独立合成层，在外层 `transform: scale()` 缩放时被位图放大，文字发虚。
* 查找命中的字符用**黄色高亮**（`::selection` 黄色背景 + 深色文字），只在查找面板打开时生效。

#### 屏蔽 WebView2 自带的查找条

* 之前按 Ctrl+F 除了打开内置面板，右上角还会弹出 WebView2 自己的"查找"浮条（工作台/查看界面同样会弹），因为 WebView2 的 `AreBrowserAcceleratorKeysEnabled` 默认为开，网页里的 `preventDefault` 拦不住。
* 1.5.1 在启动时通过 WebView2 COM 接口把它关掉（`SetAreBrowserAcceleratorKeysEnabled(false)`），因此 Ctrl+F 只会打开应用自己的查找面板。
* 副作用：F5 刷新、Ctrl+P 打印等浏览器加速键也一并禁用（发布版无影响）。

* 版本号升至 **1.5.1**（`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml` 同步）。

### 1.5.0 更新内容

#### 数据目录与备份目录调整

* 数据目录改为 **`%USERPROFILE%\\\\Documents\\\\Fastab\\\\data\\\\`**（`notes.json`、`preferences.json` 与 `assets\\\\` 都在这里）。
* 自动备份目录改为 **`%USERPROFILE%\\\\Documents\\\\Fastab\\\\FastabBackup\\\\`**，与 `data\\\\` 同级。
* **升级自动迁移**：首次启动时如果发现旧的 `Documents\\\\Fastab\\\\notes.json` / `preferences.json`（1.4.0 及更早的扁平摆放），会自动**移动**进 `Documents\\\\Fastab\\\\data\\\\`；目标文件已存在时保留现状、绝不覆盖。旧的 `Documents\\\\FastabBackup\\\\` 目录**原地保留不搬**（新备份只写新目录）。
* 设置页「备份」区块显示的目录、份数与「立即备份」都指向新目录。

#### 工作台卡片按钮

* 删除「**编辑**」「**标记完成**」两个按钮（编辑仍可双击卡片或按 Enter 进入，查看页右上角也有「编辑」按钮）。
* 新增「**置底**」按钮（图标 `>>`），把笔记排到当前视图最后一位。
* 按钮布局改为左右两组：

  * **左侧**：置顶 `<<` / 前移 `<` / 后移 `>` / 置底 `>>`；
  * **右侧**：归档 / 删除。
* 回收站视图的按钮（恢复 / 永久删除）**保持原样**。
* 「标记完成」功能已**彻底移除**：前端卡片按钮、状态标签与删除线样式，以及后端 `toggle\\\_done` 命令一并删除（`Note.is\\\_done` 字段保留在数据模型里，保证旧数据与降级安装都能正常解析）。

#### 编辑模式查找替换（Ctrl+F / Ctrl+H）

* 编辑笔记时按 **Ctrl/Cmd + F** 打开查找面板，按 **Ctrl/Cmd + H** 直接展开替换行；面板内嵌在编辑器底部右侧的圆角浮层里，两行结构：
* **第一行**：展开/折叠箭头、查找输入框、`n/N` 命中计数、↑ 上一个、↓ 下一个、选项（区分大小写 / 回绕）、× 关闭；
* **第二行**（替换模式）：替换输入框、「替换」、「全部替换」。
* 面板内快捷键：`Enter` 查找下一个、`Shift+Enter` 查找上一个、`Esc` 关闭并回到正文。
* 替换走与 Ctrl+D 相同的 `execCommand` 通道，**可以 Ctrl+Z 撤销**；「全部替换」从后往前逐处替换。
* 跳转到远处命中行时通过滚动看守器的 `scrollApi.set()` 定位，不会被"禁止跳变"逻辑弹回。
* 面板打开时正文底部自动留白，且斜杠命令浮层上移，互不遮挡。

### 开发

* Node.js（本项目使用 npm，锁文件为 `package-lock.json`）
* Rust stable（Windows 使用 MSVC 工具链）
* Tauri 2 所需系统依赖（Windows 需要 WebView2 Runtime）

> 源码目录默认\*\*不包含\*\* `node\\\_modules` 与 `src-tauri/target`（构建中间产物）。首次构建先执行 `npm install`（或 `pnpm install`）。

```bash
npm install
npm run tauri dev
npm run check
cargo check --manifest-path src-tauri/Cargo.toml
```

打包 NSIS 安装版：

```bash
npm run tauri build -- --bundles nsis
```

产物：

```text
src-tauri/target/release/bundle/nsis/Fastab\\\_1.5.6\\\_x64-setup.exe
```

> 仓库里已附带的安装包位于 `release\\\\Fastab\\\_1.5.6\\\_x64-setup.exe`；源码目录不含 `node\\\_modules`、`src-tauri/target`、`.svelte-kit`、`build` 等构建中间产物。
