# Fastab（桌面版 3.2.0）

一键呼出的轻量 Markdown 记事本（Windows x64），支持分类、回收站、自动备份、全局快捷键，
3.0.0 起支持与手机端 Fastab 的局域网同步。

当前版本：**3.2.0**

## 核心能力

* 开机自启、后台运行、一键呼出/收回（默认 `Alt + Z`），Markdown 渲染。
* **分类**：顶栏一排分类条目（「默认」固定存在），点击切换；每个分类带与文字同色的外框，
  当前分类用反色填充区分。
* **拖动排序**：顶栏分类可直接按住左右拖动，松手即保存；也可在「编辑」弹窗里拖动。
* **新建 / 编辑分类**：新建分类紧靠搜索框左侧；「编辑」支持改名、拖动排序、删除
  （删除分类后其笔记移入回收站；「默认」不可改名/删除/移动）。
* **笔记**：卡片网格 + 详情面板；新建、编辑标题与正文、置顶、移动分类、删除/恢复/彻底删除。
* **回收站**：固定入口，可一键清空。
* **自动备份**：每次保存自动快照，最多保留 20 份，可在设置里立即备份。
* **外观**：4 套主题预设（天空 / 午夜 / 自然 / 粉霞）、字体大小、显示缩放（自适应 / 90%–140%）。
* **全局快捷键 / 托盘 / 开机自启**：可在设置里调整。

## 3.0.0：手机 ↔ 电脑局域网同步

* **配对**：电脑「设置 → 设备绑定与同步」点「开始配对」，显示二维码（含 IP、端口、证书指纹、
  一次性令牌）；手机用系统相机扫码即可绑定。配对使用 HTTPS + 自签证书**指纹固定** + Bearer 令牌。
* **发送/接收**：手机工作台点「发送电脑」上传 `Phone.json` 并锁定（手机端只读）；
  电脑点「开始同步」后即可在电脑上编辑手机数据，再点「发送手机」；
  手机 1–2 秒轮询拉取、落盘、解锁，电脑收到确认后清空 `phone.json`。
* **独立命名空间**：手机数据单独存放在 `data/phone.json`，**不合并**进电脑自己的 `notes.json`；
  分类条在电脑分类之后用一条**粗竖线**隔开。
* **只读/可编辑**：只有同步会话进行中（电脑已收到手机数据、尚未发回）才允许编辑手机数据；
  其余时间只读；分类结构由手机独占，电脑只改笔记内容。
* **安全**：HTTPS（自签证书 + 指纹固定）、配对一次性令牌、设备 Bearer 令牌；
  同步服务只在配对/会话期间监听，端口默认 `47823`（被占用会顺延）。

## 数据位置

```text
Documents\Fastab\
├── data\
│   ├── notes.json          # 电脑自己的笔记
│   ├── preferences.json    # 界面偏好
│   └── phone.json          # 同步会话期间临时的手机数据（发回后删除）
├── FastabBackup\           # 自动备份（最多 20 份）
└── sync\
    ├── cert.pem            # 自签证书
    ├── key.pem             # 私钥
    └── paired.json         # 已绑定的手机与设备令牌
```

## 构建

环境要求：Node.js 18+、Rust（MSVC 工具链）、Windows 10/11。

```bash
npm install
npm run tauri build              # 产出安装包
npm run tauri build -- --bundles nsis   # 只打 NSIS 安装包
npm run tauri dev                # 开发调试
```

产物：

```text
src-tauri/target/release/fastab.exe
src-tauri/target/release/bundle/nsis/Fastab_3.2.0_x64-setup.exe
```

## 与手机版的差异

| 项目 | 电脑版 3.2.0 | 手机版 3.2.0 |
| --- | --- | --- |
| 界面 | 多列卡片 + 详情面板 + 窗口条 | 单列列表 + 底部操作面板 |
| Markdown | 渲染 | 纯文本 |
| 手机数据 | 同步会话内可编辑，会话外只读 | 手机是权威数据源 |
| 同步角色 | HTTPS 服务端（被手机连接） | 客户端（轮询拉取） |

## 已知限制

* 同步只支持 **1 台手机 ↔ 1 台电脑**、单会话；手机端锁定是防误操作的护栏，不是防篡改。
* 电脑端只编辑手机笔记的标题/正文/移动/删除/排序，分类结构只读。
* 端口变化后需要重新配对；首次监听需要放行 Windows 防火墙。
